# High School Filmmakers — website

Static site for the HSF network. Hosted free on Cloudflare Pages.

## Files
- `index.html` — Home
- `submit.html` — Submit (formats a DM, nothing is stored)
- `about.html` — About
- `styles.css` — all styling
- `favicon.svg` — icon

## Editing
Edit any file here on GitHub (pencil icon) and commit — Cloudflare Pages redeploys automatically in about a minute. The site is plain HTML/CSS, no build step.

## Reset
If a change breaks something: on the Cloudflare Pages project, open the deployments list and roll back to an earlier deployment. Or revert the commit in this repo's history.
